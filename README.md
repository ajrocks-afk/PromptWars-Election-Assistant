🗳️ Voter Navigator: AI-Powered Election Guide
Built for PromptWars 2026
Voter Navigator is an interactive web application designed to simplify the voting process for first-time voters. This project was developed using Antigravity and Gemini 3 Flash through a process of "Vibe Coding"—focusing on high-level intent and allowing AI agents to handle the underlying technical implementation.
✨ Key Features
Live Election Countdown: A real-time timer ticking down to November 3rd to build awareness.
Interactive 3-Step Process: A guided walkthrough covering Registration, Research, and Voting.
Visual Timeline: A clean, vertical timeline highlighting critical election deadlines.
Responsive Design: A modern blue-and-white theme optimized for both desktop and mobile viewing.
🛠️ Technology Stack
AI Model: Gemini 3 Flash
IDE: Google Antigravity
Frontend: HTML5, CSS3, and Vanilla JavaScript
